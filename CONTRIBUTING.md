# Contributing

Thanks for helping! This project is small on purpose: one Node.js process, no dependencies.

- **Bug?** Open an issue with your Paperclip version, what you expected and what happened. Please remove tokens, chat ids and private task content from logs.
- **Idea?** Open an issue first so we can agree on the shape before you write code.
- **Pull requests:** keep them focused, no new dependencies, run `npm run check` before pushing.
- New user-facing text goes through the strings table so it can be translated.
